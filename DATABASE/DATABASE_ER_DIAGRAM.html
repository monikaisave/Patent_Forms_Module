🏛️ Patent Forms Module & Database Schema

Database: patent_forms_standalone_db (MySQL / MariaDB on Port 3307/3306)

PK Primary Key
FK Foreign Key / Join Ref
VARCHAR / INT Types
📄 patentapplication
Master Patent Registry
PK patentId INT(11) AUTO_INCREMENT Primary Record Key
KEY fileNo VARCHAR(250) UNIQUE Unique File No (641D, 634P)
type VARCHAR(100) 'Patent' or 'Design'
clientRefNo VARCHAR(250) Client Reference
applicationNo VARCHAR(250) Statutory IPO App No
titleOfInvention TEXT Full Invention Title
dateOfFiling DATE Filing Date
priorityDate DATE Priority Convention Date
typeOfApplication VARCHAR(150) 'Ordinary', 'Convention', etc.
REF applicantsId VARCHAR(250) CSV IDs -> applicants
inventorsData TEXT Serialized inventor info
👥 applicants
Applicants & Inventors Directory
PK applicantId INT(11) AUTO_INCREMENT Primary Key
applicantName VARCHAR(255) NOT NULL Company / Person Name
applicantAddress TEXT Postal Address for Service
applicantEmail VARCHAR(255) Official Notification Email
applicantPhone VARCHAR(50) Contact Phone Number
isDelete TINYINT(1) DEFAULT 0 0 = Active, 1 = Deleted
🌍 patentcountry
Section 8 Foreign Filings
PK pCountryId INT(11) AUTO_INCREMENT Primary Key
FK fileNo VARCHAR(250) NOT NULL Links to patentapplication.fileNo
countryAbbreviation VARCHAR(255) NOT NULL Country / Jurisdiction Name
countryDate VARCHAR(100) Date of Application Abroad
countryComment VARCHAR(255) Foreign Application Number
isStop TINYINT(1) DEFAULT 0 0 = Pending, 1 = Abandoned
📝 patent_form_submissions
Forms, Drafts & Dynamic JSON Payloads
PK id INT(11) AUTO_INCREMENT Primary Key
FK file_no VARCHAR(250) NOT NULL Links to patentapplication.fileNo
form_code VARCHAR(100) NOT NULL e.g. indian_patent_form_1
form_title VARCHAR(255) NOT NULL Statutory Display Title
form_data LONGTEXT NOT NULL Complete JSON payload
status VARCHAR(50) DEFAULT 'draft' 'draft' or 'submitted'
created_at DATETIME DEFAULT CURRENT_TIMESTAMP Created Timestamp
updated_at DATETIME ON UPDATE CURRENT Last Modified Timestamp

🔗 Relational Foreign Key Connections

➜ patentcountry.fileNo (Many) ───[Foreign Key]───► patentapplication.fileNo (One)
➜ patent_form_submissions.file_no (Many) ───[Foreign Key]───► patentapplication.fileNo (One)
➜ patentapplication.applicantsId (CSV) ───[FIND_IN_SET Join]───► applicants.applicantId (Many-to-Many)
